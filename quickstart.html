Quick Start Guide

Issue your first certificate on Solana devnet in under 5 minutes.

Prerequisites

  • Node.js (16+)
  • A running backend API (see backend README)
  • Solana CLI and devnet access (optional for on-chain issuance)

Steps

  1. Start the backend API (example): 
    cd backend
npm install
npm run start
  2. Open the frontend and navigate to the Issue flow (or use API): 
    POST /api/certificates/issue
Content-Type: application/json
Authorization: Bearer <issuer-token>

{
  "certificateId": "cert-12345",
  "holderName": "Alice Example",
  "holderEmail": "alice@example.com",
  "certificateType": "Completion",
  "issuerName": "Example Academy",
  "issuerWallet": "",
  "onChain": false
}
  3. Verify the certificate by calling the verification endpoint or using the Verify UI.
